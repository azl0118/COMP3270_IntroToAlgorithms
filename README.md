# COMP 3270 - Introduction to Algorithms

This repository contains homework and programming assignments completed for COMP 3270: Introduction to Algorithms.

Auburn University

The course focuses on designing, analyzing, and evaluating algorithms used to solve computational problems. Topics include algorithm efficiency, time complexity, algorithm design techniques, and performance analysis.

## Course Topics

- Algorithm design and correctness proofs
- Time and space complexity (Big O, Omega, Theta)
- Recursion and recurrence relations
- Sorting and searching algorithms (Quick Sort, Merge Sort, Heap Sort, etc.)
- Priority queues, binary heaps, and disjoint sets
- Graph algorithms (BFS, DFS, topological sorting)
- Minimum spanning trees (Prim's and Kruskal's algorithms)
- Shortest path algorithms (Dijkstra's and Bellman-Ford)
- Introduction to machine learning and probabilistic algorithms
- Computational complexity (P, NP, NP-completeness)

## Assignments and Main Project

### Homework 1 - Algorithm Analysis and Correctness

Analyzed algorithm time complexity, developed problem-solving strategies, and explored algorithm correctness through mathematical induction, loop invariants, and recursive algorithms.

### Homework 2 - Recurrence Relations and Complexity Analysis

Analyzed algorithm efficiency using asymptotic notation and recurrence relations. Applied recursion trees, substitution, and the Master Method to determine time complexity and used loop invariants to prove algorithm correctness.

### Homework 3 - Sorting Algorithms and Data Structures

Explored sorting algorithms, heap operations, and disjoint-set data structures. Analyzed Quickselect, Counting Sort, Radix Sort, and Bucket Sort, along with union-find optimizations, path compression, and binomial heaps.

### Homework 4 - Graph Algorithms and Clustering

Applied graph algorithms including BFS, DFS, topological sorting, and Bellman-Ford shortest paths. Analyzed graph representations, minimum spanning tree updates, and K-Means clustering through iterative centroid calculations and visualizations.

### Programming Assignment - Matrix Multiplication Analysis

Implemented and compared five matrix multiplication algorithms: standard, blocked, recursive, divide-and-conquer, and Strassen's algorithm.

- Measured execution times across different matrix sizes.
- Compared empirical performance with theoretical time complexity.
- Visualized algorithm performance using graphs.
- Implemented dynamic programming for matrix chain multiplication to compare sequential and optimal multiplication orders.

**Technologies:** Python, NumPy, Pandas, Matplotlib, Jupyter Notebook
